# Reviewer bookmarks

Original literal text and OOXML authored for #1212; MIT, John Scrudato IV. Generated from
`bookmark_reviewer_cases()` in JSv4/docx-fidelity-bench, with no imported document content.

Each case has base (`-0`), two reviewer (`-1`, `-2`) inputs and the combined `-final` expectation.
The base is also the rejected expectation. Paragraph, content-control and cell cases pair an edit
inside the bookmark with an edit outside it. The final pair checks independent bookmark movement
and removal against a single-remover control.
