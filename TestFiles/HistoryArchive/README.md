# Real portable-history artifacts

These files are test inputs and usable examples, not output regenerated by normal tests.

| File | Contents |
| --- | --- |
| `agreement.docxhistory` | Real services agreement: original, revised, same-content named version, restore. |
| `charter-collaboration.docxhistory` | Real NVCA charter: saves, restore, accepted package edit, conflicting proposal, explicit discard, final label. |
| `*-vN.docx` | Exact oldest-first snapshots exported from those archives. |
| `*-comparison.docx` | Native tracked-change comparison of a selected non-latest pair, asserted byte-for-byte. |
| `*-conflicting-proposal.docx` | Preserved conflicting work, separate from the accepted latest version. |
| `*.json` | Test indexes: exact head/version IDs, snapshot and comparison filenames, SHA-256 checksums. |

Sources: existing `TestFiles/VP/VP004-Legal-Contract.docx` and `TestFiles/NVCA-Model-COI.docx`.
The metadata describes fictional test work, not actual professional advice or approvals.

Verify without modifying fixtures:

```bash
dotnet test Docxodus.Tests/Docxodus.Tests.csproj \
  --filter FullyQualifiedName~DocxHistoryArchiveArtifactTests
```

Explicitly regenerate these checked-in samples after an intentional fixture change:

```bash
DOCXODUS_REBUILD_HISTORY_FIXTURES=1 dotnet test Docxodus.Tests/Docxodus.Tests.csproj \
  --filter FullyQualifiedName~DocxHistoryArchiveArtifactTests
```

Regeneration changes version IDs/nonces, ZIP packaging bytes and the JSON indexes, even
when the underlying document content is unchanged. Review all resulting
binary and metadata changes together. Ordinary DOCX files contain no external history;
open the `.docxhistory` file through `DocxHistoryArchive.OpenAsync` to browse it.
